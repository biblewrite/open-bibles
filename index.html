Use it as an API

Every file is served with Access-Control-Allow-Origin: *. Fetch it from a browser, a worker, anywhere — no key, no rate limit, no build step.

const john = await (await fetch(
  '/translations/eng-kjv2006/books/43-JHN.json'
)).json()

john.chapters.find(c => c.chapter === 3)
             .verses.find(v => v.verse === 16).text

// what exists
const catalog = await (await fetch('/catalog.json')).json()

Books run 01-GEN to 66-REV, numbered so a listing sorts the way a Bible does. Per-translation detail — book list, verse counts, the publisher's own copyright notice — is in translations/<id>/meta.json.

Texts from eBible.org. Each translation keeps its own licence: 17 are public domain, the rest are copyrighted but published as redistributable. This site relicenses nothing — reproduce a translation's notice if you ship it. Source on GitHub.
