Use it as an API

Every file is served with Access-Control-Allow-Origin: *, so fetch it straight from the browser. No key, no rate limit.

// one book
const john = await (await fetch(
  '/translations/eng-kjv2006/books/43-JHN.json'
)).json();

john.chapters.find(c => c.chapter === 3)
            .verses.find(v => v.verse === 16).text;

// what exists
const catalog = await (await fetch('/catalog.json')).json();
catalog.translations.filter(t => t.language === 'Telugu');

Books are numbered by canonical order — 01-GEN through 66-REV. Per-translation details, including the publisher's own copyright notice, are in translations/<id>/meta.json.
